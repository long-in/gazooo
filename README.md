# gazooo

パソコンの中だけで動く、画像生成アプリです(Windows / macOS)。文章(プロンプト)から画像を作り、作った画像とその設定をまとめて管理できます。
画像の生成には [ComfyUI](https://github.com/comfyanonymous/ComfyUI) を使います。ComfyUI のインストールも、アプリの中から行えます。

## できること

- **画像の生成**: Stable Diffusion(SD1.5 / SDXL)、Flux.1(通常 / GGUF)、Anima、Qwen-Image 2.1、Krea 2 に対応しています。アニメ向けのモデルも選べます。
- **いろいろな作り方**: 画像からの変換(img2img、アニメ調への変換)、一部だけ描き直す(Inpaint)、参照画像で構図を固定する(ControlNet)、顔の補正、参照画像を使った編集(Qwen-Image 2.1)。
- **ギャラリー**: 作った画像を検索し、お気に入りに登録し、同じ設定で作り直したり、書き出したりできます。プロンプトと設定は画像と一緒に保存されます。
- **プリセット**: よく使う設定を名前を付けて保存できます。
- **モデルの取得**: モデルを一覧から選んでダウンロードできます(取得元・サイズ・ライセンスを確認してから導入します)。
- **AI サポート**(任意): 設定の相談や、日本語のプロンプトを英語へ翻訳・校正する機能です。クラウド(Anthropic の Claude)か、パソコン内で動くローカル LLM を選べます。
- **ユーザー**: 1 台のパソコンを複数人で使えます。ユーザーごとに設定・画像・プロンプトが別になります。
- **バックアップ**: 設定・ギャラリー・プリセットを 1 つのファイルに保存し、あとから復元できます。

## 使い方

### 1. 準備

1. アプリを起動すると、ユーザーを選ぶ画面が出ます。最初は **[最初のユーザーを作成]** で名前を付けて始めます。
2. **ComfyUI を用意します**(次のどちらか)。
   - **アプリから導入する**: 設定 > エンジン から ComfyUI(Python・PyTorch を含む)を導入できます。数 GB のダウンロードがあります。
   - **お持ちの ComfyUI を使う**: そのまま使えます。既定の接続先は `http://127.0.0.1:8188` で、設定画面で変更できます。
3. **モデルを入れます**。左のメニューの「モデル」から、使いたいモデルを選んでダウンロードします。数 GB から数十 GB になるものがあります。
4. 画面下部のステータスバーで ComfyUI の接続が緑になれば、生成できます。

### 2. 画像を作る

1. 「生成」画面でモデルを選び、プロンプト(作りたい絵の説明)を入力して [生成] を押します。
2. 生成は順番待ち(キュー)に入ります。画面の下部に、待機中・実行中の生成と、できあがった画像が並びます。
3. 画像を選ぶと、設定を読み込み直して続きから作れます(「ベースにする」)。

プロンプトは、モデルによって書き方が違います(Stable Diffusion 系は英語、アニメ系は Danbooru タグ など)。生成画面のモデルの説明と、AI サポートの翻訳機能が役に立ちます。

### 3. ユーザーとロック

- 起動時に表示されるユーザーの一覧から、使う人を選びます。左のメニューの一番上のアイコンから、ユーザーを切り替えられます。
- **ユーザーごとに別のものになるもの**: 設定、ギャラリー、プロンプト、プリセット、AI サポートの会話と API キー。ほかのユーザーのものは、アプリの画面から見えません。
- **ComfyUI・モデルの保存先・デバッグなどは、全ユーザーで共通です。**
- **ロック**(任意): 設定 > その他 で、PIN(4〜8 桁の数字)またはパスフレーズ(8 文字以上)を設定できます。初期状態では無効です。PIN は、ログイン画面の数字キーパッドをクリックするか、キーボードの数字キーで入力します。
  - 入力を間違え続けると、しばらく入力できなくなります(5 回で 30 秒。以降は倍々に、最大 15 分)。

### 4. バックアップ

設定 > その他 > バックアップ で、設定・ギャラリー・プリセットを選んで 1 つのファイル(`.gazooo-backup`)に保存できます。復元は、選んだ項目を **置き換える** 形で行われ、**元に戻せません**。復元の前に、必要なら現在のデータのバックアップを取ってください。バックアップは、ログイン中のユーザーのデータが対象です。

## 注意点

### 動作環境

| | Windows | macOS |
|---|---|---|
| OS | Windows 10(22H2)/ 11 | macOS 13 以降(Apple Silicon) |
| GPU / メモリ | VRAM 8GB 以上の NVIDIA GPU | ユニファイドメモリ 16GB 以上(Flux は量子化モデルを推奨) |

AMD・Intel の GPU(Windows)は動作を確認していません。空き容量は、モデルや ComfyUI のぶん、数十 GB を見込んでください。メモリ不足で失敗するときは、解像度やバッチ数を下げてください。

### インストーラについて(未署名)

現時点のインストーラは **コード署名・公証をしていません**。

- Windows: SmartScreen の警告が出ます。「詳細情報」→「実行」で進めます。
- macOS: 初回は Gatekeeper の警告が出ます。macOS 15 以降は「システム設定 → プライバシーとセキュリティ → このまま開く」、それ以前は右クリック →「開く」で進めます。

### 外部との通信

画像の生成や、画像・プロンプトの保存は、すべてパソコンの中で行います。次の場合だけ、インターネットに接続します。

- **モデル・ComfyUI などのダウンロード**(Hugging Face・GitHub など。導入の操作をしたときだけ)。
- **AI サポート(クラウド)を使うとき**: プロンプトや設定、相談の内容が Anthropic に送られます。利用するには、ご自身の API キーの登録と、同意が必要です。API キーは、パソコン内に **暗号化されずに** 保存されます。
- ローカル LLM やローカルの翻訳専用モデルを使うときは、内容は外部に送られません(導入時のダウンロードを除く)。

### ロックについて

ロックは、**アプリの画面で他のユーザーに見せないための保護**です。**ファイルは暗号化されません**。同じ Windows / macOS のアカウントでフォルダを直接開けば、画像やデータは読めてしまいます。大切なものを守りたいときは、OS のアカウントを分けるか、ディスクの暗号化(BitLocker / FileVault)を併用してください。
**PIN・パスフレーズを忘れても、復旧はできません。** そのユーザーを削除して作り直すことになり、そのユーザーのデータは失われます。

### モデルと生成物の利用について

- モデルにはそれぞれ **ライセンスと利用条件** があります(例: Flux.1 dev は非商用)。ダウンロード時の確認画面で取得元とライセンスを確認し、条件を守ってお使いください。
- モデルごとに規制の強さ(出力の制限の度合い)が異なります。モデルの説明で確認できます。**実在の人物を無断で描くこと、未成年を性的に描くこと、違法な利用は認められません。** 生成物の利用は、ご自身の責任で適法に行ってください。
- アプリの更新やモデルの変更で、同じプロンプト・同じ設定でも、同じ画像にならないことがあります。

### データの場所

| | Windows | macOS |
|---|---|---|
| ユーザーのデータ(DB・画像) | `%APPDATA%\dev.gazooo.desktop\users\<ユーザーごとの ID>\` | `~/Library/Application Support/dev.gazooo.desktop/users/<ユーザーごとの ID>/` |
| 共通のデータ(ユーザー一覧・ComfyUI の設定) | `%APPDATA%\dev.gazooo.desktop\app.db` | `~/Library/Application Support/dev.gazooo.desktop/app.db` |
| ログ | `%LOCALAPPDATA%\dev.gazooo.desktop\logs\` | `~/Library/Logs/dev.gazooo.desktop/` |

- 画像の保存先は、ユーザーごとに設定画面で変更できます(既存の画像を移動するかを選べます)。
- **アンインストールしても、データは残ります。** 完全に消したいときは、上のフォルダを手動で削除してください。
- 以前のバージョン(ユーザー機能の前)から更新した場合、それまでのデータは、最初のユーザー「ユーザー 1」に引き継がれます。古いデータベースは `gazooo.db.pre-users` として残ります。

### 既知の制限

コード署名なし / アイコンは暫定 / 自動アップデートなし / 生成中のプレビュー、LoRA は未対応 / ユーザーごとのデータの暗号化なし。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 「ComfyUI に接続できません」と出る | ComfyUI が起動しているか確認します(アプリから導入した場合は、設定 > エンジン で起動できます)。接続先の URL も確認してください。 |
| モデルが選べない | 「モデル」画面でダウンロードできているか、モデルの保存先が ComfyUI の読む場所と合っているか(設定 > 保存先)を確認します。 |
| 生成が失敗する | 解像度・バッチ数を下げます。必要なカスタムノードが無い場合は、ComfyUI を更新してください。 |
| 調査したい | 設定 > その他 でデバッグログを有効にし、ログを ZIP で書き出せます。ログにはプロンプトの本文や API キーは含まれません。 |
