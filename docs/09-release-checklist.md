# 09. リリース前の手動検証チェックリスト

自動テストでは確認できない項目(実際の画像生成、画面操作、インストーラ、OS 固有の挙動)を、**リリース前に Windows 11 と macOS の実機で**確認する。
GitHub Releases の下書きを公開する前に、すべての項目を確認し、結果を §12 に記録すること。

> ステータス: 🟢 承認済み(2026-11-19)

## 0. 事前条件

- [ ] `develop` の対象コミットで **CI が成功**している(`check` と `bundle`)。
- [ ] バージョンを更新した(`package.json` / `src-tauri/Cargo.toml` / `src-tauri/tauri.conf.json`)。`node tools/check-version.mjs` が通る。
- [ ] タグ `vX.Y.Z` を push し、`release.yml` が **下書き** のリリースを作った。
- [ ] 検証用の ComfyUI を用意した(`npm run comfyui:setup` / `start`、または公式ポータブル版)。
- [ ] 検証用のモデルを配置した(下表)。ライセンス(特に Flux.1 dev は非商用)を確認した。

| 検証対象 | 必要なモデル(例) |
|---|---|
| SDXL | チェックポイント 1 つ(`models/checkpoints/`) |
| Flux GGUF | GGUF の拡散モデル(`models/unet/`)、T5 と CLIP-L(`models/clip/`)、`ae.safetensors`(`models/vae/`)。ComfyUI-GGUF ノード |
| Flux(通常) | `models/unet/` に safetensors、同上のテキストエンコーダと VAE |

検証環境: Windows 11(NVIDIA GPU)/ macOS(Apple Silicon、メモリ 16GB 以上)。

## 1. インストール・起動

- [ ] 下書きリリースのインストーラをダウンロードして実行できる。
  - Windows: SmartScreen の警告(未署名)を「詳細情報 → 実行」で進められる。管理者権限を求められない。
  - macOS: `.dmg` を開き、`/Applications` へコピーできる。初回は Gatekeeper の警告が出る(macOS 15 以降は「システム設定 → プライバシーとセキュリティ → このまま開く」。それ以前は右クリック → 開く)。「壊れているため開けません」と出る場合は署名の不具合(`codesign --verify --deep --strict` で確認)。
- [ ] アプリが起動し、ウィンドウが表示される(白画面でない)。最小サイズ(960×640)より小さくできない。
- [ ] 日本語の UI が表示される。OS のロケールが英語なら英語になる。
- [ ] データ保存先が作られる。
  - Windows: `%APPDATA%\dev.gazooo.desktop\`(`gazooo.db`、`images\`)/ ログ: `%LOCALAPPDATA%\dev.gazooo.desktop\logs\`
  - macOS: `~/Library/Application Support/dev.gazooo.desktop/` / ログ: `~/Library/Logs/dev.gazooo.desktop/`

## 2. ComfyUI 接続

- [ ] ComfyUI を **停止した状態**で起動 → サイドバーが「ComfyUI 未接続」(赤)、生成画面にバナーが出る。生成ボタンが無効。
- [ ] ComfyUI を起動 → 約 5 秒以内にバッジが緑になり、バナーが消える。
- [ ] ComfyUI を停止 → 約 5 秒以内に未接続になる(アプリを再起動せずに)。
- [ ] 設定で別の URL(存在しないポート)を保存 → 未接続になり、元の URL に戻すと接続される。「再接続」ボタンが効く。
- [ ] http でも https でない URL(`ftp://…`)は保存時にエラー表示される。

## 3. 生成(SDXL)

- [ ] モデル種別 SDXL を選ぶと、チェックポイントの一覧が出て、先頭が自動選択される。
- [ ] プロンプトを入力して「生成」(または `Ctrl/⌘ + Enter`)→ 進捗バーが進み、完了すると画像が表示される。
- [ ] 画像が `images/YYYY/MM/<id>.png` に保存され、サムネイルが `images/thumbs/` に作られる。
- [ ] 枚数 3 で生成 → キューに 3 件が順に実行される(シードがランダム / 固定なら +1 ずつ)。
- [ ] 実行中に「キャンセル」(または `Esc`)→ 取り消され、次のジョブへ進む。ComfyUI 側も中断されている。
- [ ] 待機中ジョブの並べ替え(上へ / 下へ)が、実行順に反映される。待機中のキャンセルができる。
- [ ] 存在しないモデルが選ばれた状態で生成 → 「モデルが見つかりません」と表示され、モデル一覧が更新される。
- [ ] 失敗したジョブを「再試行」できる。
- [ ] (可能なら)大きすぎる解像度で生成 → メモリ不足の失敗に、解像度を下げるヒントが出る。

### 3.1 顔補正(v0.2。SD 1.5 / SDXL)

- [ ] Impact Pack・Subpack と検出モデルが **無い** ComfyUI では、「顔補正」のスイッチが無効になり、導入が必要な旨が出る。Flux 系の種別を選んでも無効になり、「SD 1.5 / SDXL のみ」と出る。
- [ ] 導入済みの ComfyUI で、スイッチを入れると検出モデル・強さ・補正用プロンプトが出る。顔が写るプロンプトで生成 → 進捗が「生成中」から「顔補正中」に変わり、完了後に顔が自然に整う。
- [ ] 顔が写らない絵でも、エラーにならず画像が保存される。
- [ ] ギャラリーの詳細に「顔補正」の設定が表示され、「この設定で生成」とプリセットで設定が復元される。

### 3.2 ControlNet(v0.2。SD 1.5 / SDXL)

- [ ] ControlNet モデルが無い ComfyUI では、「ControlNet」のスイッチが無効になり、置き場所の案内が出る。Flux 系の種別でも無効になる。
- [ ] スイッチを入れ、「ファイルを選ぶ」で PNG / JPEG を選ぶと、サムネイルとサイズが出る(ダイアログのキャンセルでは何も変わらない)。画像以外のファイルを選ぶとエラーが出る。
- [ ] 参照画像が未選択のあいだ、「生成」が押せない。選ぶと押せる。
- [ ] Canny で生成すると、参照画像の輪郭に沿った構図の画像ができる。縦横比が違う参照画像では、中央を切り抜く旨が出る。
- [ ] 前処理を Depth / OpenPose に変えると、名前の合うモデルに切り替わる(controlnet_aux 導入済みの場合。未導入ならその選択肢は出ず、案内が出る)。
- [ ] ギャラリー詳細の「参照画像に使う」で、生成画面へ移動し、その画像が参照画像になって ControlNet が有効になる。
- [ ] 保存したプリセット・「この設定で生成」で参照画像ごと復元される。参照画像のファイルを消してから復元すると、ControlNet が無効になり通知が出る。
- [ ] 保存先を変更して「移動する」を選ぶと、参照画像も新しい保存先へ移り、復元・生成ができる。

### 3.2.1 Inpaint(v0.5。SD 1.5 / SDXL。設計: 13)

- [ ] Flux 系の種別では「Inpaint」のスイッチが無効になる。顔補正が有効なときも無効になり、先に顔補正を切る旨が出る。Inpaint を有効にすると顔補正が無効になる。
- [ ] 参照画像を選ぶと、サムネイル・サイズが出て、生成サイズが画像に合う(Inpaint が有効な間は幅・高さを変えられない)。64 の倍数でない画像では、拡大・縮小する旨の注記が出る。
- [ ] 「マスクを描く」で、ブラシ・消しゴム・ブラシの大きさ・元に戻す(Ctrl/Cmd+Z)・反転・全消去が動く。何も塗らずに保存するとエラーが出る。保存後は「マスクを編集」で再編集でき、塗った範囲が復元される。
- [ ] 参照画像かマスクが未設定のあいだ「生成」が押せず、理由が出る。
- [ ] 顔を塗って「反転」したマスクで生成すると、顔以外が描き直され、**顔の画素が元画像と同一**になる(「結果を元画像へ合成し直す」が有効、元画像が 64 の倍数のとき)。無効にすると境界が変化する。
- [ ] 強さ(denoise)を上げると元画像から離れ、下げると近づく。マスクの拡張・ぼかしで境界のなじみが変わる。枚数 2 以上でも全枚が生成される。
- [ ] ControlNet と併用できる。
- [ ] ギャラリー詳細の「Inpaint に使う」で、生成画面へ移動し、その画像が参照画像になって Inpaint が有効になる。詳細に Inpaint の設定が表示される。
- [ ] 保存したプリセット・「この設定で生成」で、画像・マスクごと復元される。ファイルを消してから復元すると、Inpaint が無効になり通知が出る。
- [ ] ComfyUI に必要なノードが無い場合、スイッチが無効になり案内が出る(古い ComfyUI で確認)。

### 3.6.1 Qwen-Image 2.1 の参照画像つき生成(v0.16、設計: 24。M20)

## 既知の制限(リリースノートに記載する)

- コード署名・公証なし(SmartScreen / Gatekeeper の警告)。
- アイコンは暫定(Tauri 既定)。
- 自動アップデートなし。
- 生成中のプレビュー画像、LoRA、Inpaint 以外の img2img・アウトペイントは未対応。
- 顔補正(v0.2)は SD 1.5 / SDXL のみ。ComfyUI に Impact Pack・Impact Subpack と検出モデルが必要。
- ControlNet(v0.2)は SD 1.5 / SDXL のみ、1 ユニット。Canny 以外の前処理には comfyui_controlnet_aux と ControlNet モデルが必要。前処理結果のプレビューなし。
- AI サポート(v0.3)は利用者自身の Anthropic API キーが必要で、利用料は利用者に請求される。キーは DB に平文で保存され、会話履歴(プロンプト本文を含む)も同じ DB に残る。
- 画像生成には ComfyUI が必要。設定画面からアプリ専用のフォルダに自動でインストールできる(v0.15。Windows x64 の NVIDIA GPU と macOS Apple Silicon、基本で約 4〜5GB・顔補正などの追加で増える)。既存の ComfyUI にも接続できる。モデルの配置は別途必要。
- アプリをアンインストールしても、アプリが導入した ComfyUI とモデル(アプリのデータフォルダ内)は残る。先に設定画面の [削除] を使うこと。
- AMD / Intel GPU(Windows)は検証対象外。
- ローカル LLM(v0.23)は Windows x64 と macOS Apple Silicon のみ。導入に約 5.7GB のダウンロードが必要で、GPU のメモリが少ない環境では遅くなる。Ollama など外部サーバのメモリはアプリでは管理しない。

- [ ] (34 §9.14)設定 > プロンプト翻訳で、翻訳専用モデルを導入できる(同意ダイアログでライセンス全文が読め、「Built with PLaMo」が出る。進捗・中止・削除が動く)。導入後に翻訳エンジンで選べ、削除すると自動で「送信先の LLM」に戻る。翻訳専用モデルの起動中に本体のローカル LLM を使うと、もう一方が停止する(逆も同じ)。
- [ ] 翻訳エンジン = 翻訳専用モデルで、[翻訳のみ] がキー・同意なし・外部通信なしで動く。[翻訳+校正] が 2 段で動き、2 段目を断らせたときは 1 段目の結果が入って「校正できなかった」と出る。Qwen-Image 2.1 では 1 段目を飛ばす。


### M30(バックアップ)の手動確認項目(未実施。docs/35)

- [ ] 設定 > その他 > バックアップで、設定値・ギャラリー・プリセットのトグルが既定すべて ON。3 つとも OFF にすると [バックアップを保存…] が押せない。ギャラリーの件数・容量の見込みが出る。
- [ ] 画像を含むバックアップを保存 → 進捗が出る・キャンセルで書きかけのファイルが消える・完了のトースト。取得中も生成・画面操作ができる。API キーは既定で入らない(ZIP の `db/gazooo.db` に `assistant.api_key` が無い)。
- [ ] 別のデータ(新規インストール相当)で [バックアップを選んで復元…] → 内容(日時・件数)が出る。区分を選んで復元でき、選ばなかった区分は変わらない。完了後に再起動して、設定・プリセット・会話・ギャラリー(画像・サムネイル)・参照画像が戻っている。
- [ ] 実行中のジョブがあるとき、確認なしでは復元できず、確認すると停止して復元される。
- [ ] 別 PC(ComfyUI のパス・画像保存先が存在しない)で復元。画像保存先が作られ、ギャラリーが表示される。設定値のみ復元でギャラリーを復元しないとき、保存先の変更の警告が出る。
- [ ] 「バックアップに無い画像ファイルを削除する」ON で、件数・容量が出て、ゴミ箱へ移る(OFF では残る)。
- [ ] 壊れたファイル・新しいバージョンのバックアップは、何も変更せずエラーになる。macOS でも同様。
