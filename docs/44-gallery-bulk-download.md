# 44. ギャラリーの複数選択ダウンロード(v0.40)

> ステータス: 🟢 承認済み・実装済み(2026-11-24。07 Q-372〜380 は推奨どおり。Rust・Vitest・clippy・tsc・ESLint まで確認。**画面の目視確認・実機のフォルダ選択・macOS は未実施**。差異は §8)。
> **経緯**: ユーザー要望「ギャラリーページで複数選択のダウンロード機能がほしい」(2026-11-24)。

## 1. 目的とスコープ

**やること**
- ギャラリーで複数選択した画像(既存の選択機能。`selected`)を、**[ダウンロード] で、指定したフォルダへまとめて保存**する。
- 保存するのは **原寸の画像ファイルそのもの**(再エンコードしない。ComfyUI が埋め込んだプロンプト等のメタデータも保たれる)。
- 保存先フォルダは Rust 側のダイアログで選ぶ。名前の衝突は連番で避ける。
- 進捗と結果(成功・失敗の件数)を表示し、完了後に [フォルダを開く] を出す。

**やらないこと**
- 形式の変換・リサイズ(必要なら 43 の変換ページを使う。ギャラリーからの連携は作らない)。
- ZIP 化(§6 Q-374)。クラウドへのアップロード・共有。
- 単体の保存(既存の `image_export`)の変更。

## 2. 画面(05・27・37 への追記)

- 選択中に出る一括操作バー(「N 件選択 / すべて選択 / プロジェクトへ移動 / 削除」)に **[ダウンロード]** を追加する(§4 の「画像が 1 枚だけ」の場合も同じボタン)。
- グリッド・ビューア(37)のどちらでも、選択があれば使える。ビューアでは選択が無いとき、従来の単体保存のまま。
- 押すと **フォルダ選択ダイアログ**(Rust 側)を開く。キャンセルなら何もしない。
- 保存中: バー内に「保存中 3 / 12」と **[中止]**。完了後に toast「12 枚を保存しました」+ **[フォルダを開く]**。失敗があれば件数を出し、詳細(ファイル名・理由)を開ける。
- 前回の保存先を、次回のダイアログの初期位置にする(設定ストア。ユーザーごと。36)。

## 3. 動作

- 対象は **選択中の画像の ID**(最大 1000 枚。超える場合は選択を促す)。ID は既存の DB から原寸のパスを引く(`ImageService::original_path`)。パスはフロントから受け取らない。
- 保存名: **画像の元のファイル名**(ギャラリーの保存名)を基本とする。同名は ` (1)`・` (2)` … の連番で衝突を避け、**既存ファイルは上書きしない**。
- 書き込みは一時ファイル → 名前変更。失敗・中止で途中のファイルを残さない(43 §5 と同じ)。
- 元の画像ファイル(ギャラリーの管理領域)は変更しない。ファイルが既に無い画像は失敗として数え、他は続行する。
- 保存先が管理領域(ギャラリーの保存先)の内側なら拒否する(自分自身へのコピーを防ぐ)。
- 1 枚の失敗で全体を止めない。中止は、実行中の 1 枚を完了させ、未着手は処理しない。

## 4. IPC(04 への追記)

| コマンド | 引数 | 戻り値 | 説明 |
|---|---|---|---|
| `image_export_many` | `{ ids: string[] }` | `{ jobId: string } \| null` | Rust 側でフォルダ選択ダイアログを開き、選ばれたら保存を開始する。キャンセルは `null` |
| `image_export_cancel` | `{ jobId }` | `void` | 中止(未着手を処理しない) |

イベント: `image-export://progress`(`{ jobId, done, total }`)、`image-export://done`(`{ jobId, ok, failed: { id, error }[], dir }`)。`dir` は [フォルダを開く] 用(既存の `image_reveal` と同様に Rust 側で開く)。

## 5. 実装方針

- Rust: `ImageService::export_many`(コピーは `spawn_blocking`。同時実行は 1〜2 本で十分)。名前の衝突回避・一時ファイルは 43 の出力処理と **共通のヘルパー**を使う(重複実装しない)。パス操作は `std::path`(Windows / macOS。06)。
- フロント: `src/lib/tauri/` に薄いラッパー、ギャラリーのストアに状態(進捗・結果)を追加。
- DB スキーマ変更なし。バックアップ対象の変更なし。

## 6. テスト

- Rust: 連番の衝突回避、既存ファイルを上書きしない、欠落ファイルが失敗に数えられ続行すること、管理領域の内側への保存を拒否、中止で未着手が処理されないこと、一時ファイルが残らないこと。
- Vitest: [ダウンロード] が選択ありのときだけ有効、進捗表示、キャンセル時に何も起きないこと。
- 09 に追加: 複数選択 → ダウンロード → 指定フォルダに原寸が並ぶ(メタデータが残る)、同名の連番、[フォルダを開く]、中止。

**マイルストーン M39**: ① Rust(`image_export_many`・共通ヘルパー)→ ② ギャラリーの UI(ボタン・進捗・結果)→ ③ 09 の項目・docs の同期。

## 8. 実装時の差異

- **[ダウンロード] はグリッド表示の一括操作バーだけに置いた**(ビューア表示には選択の UI が元々無いため。§2 のビューアの記述は取り下げ)。
- `image-export://done` に `error`(開始前の検証エラー。例: 保存先が管理領域の内側)を追加した。
- [フォルダを開く] は、`image_export_open_dir`(引数なし)が **前回の保存先**(設定ストア `gallery.export_dir`)を開く。パスをフロントから受け取らないため、§4 の `done.dir` は持たない。
- 連番のヘルパーは 43 の `choose_output` を `pub(crate)` にして共用した。一時ファイルの拡張子は `<ext>.gazooo-tmp`。
- 保存先の前回値は DB の設定(ユーザーごと)に保存する。

## 9. 追補: Shift+クリックの範囲選択(v0.43。🟢 承認済み・実装済み 2026-11-24。Vitest 384・tsc・ESLint まで確認。画面の目視確認は未実施)

> **経緯**: ユーザー要望「シフト+クリックで複数選択して削除・ダウンロードできるようにしたい」(2026-11-24)。削除・ダウンロードの一括操作は §2 のとおり実装済みのため、**不足していた選択操作だけ**を足す。対象はギャラリーのグリッド表示のみ(生成ページの帯は変更しない)。

### 9.1 現状

- Ctrl / Cmd / Shift + クリックは、いずれも **その 1 枚の選択を切り替える**だけ(Shift に特別な動作は無い)。
- 一括操作バー(§2)の [ダウンロード]・[削除] は選択があれば使える。

### 9.2 変更点

- **Shift + クリック = 範囲選択**。直前にクリック(選択・解除)した画像(**アンカー**)から、クリックした画像までの **表示順で連続する範囲をすべて選択**する。
  - アンカーが無い(選択が空で最初の操作)場合は、その 1 枚だけを選択してアンカーにする(従来と同じ)。
  - アンカーが現在の一覧に無い(絞り込み・スコープ切り替え・削除で消えた)場合も同様に、その 1 枚だけを選択する。
  - 範囲の選択は **追加**(すでに選択済みの画像は保つ)。範囲を縮める操作は、個別に Ctrl + クリックで外す。
- **Ctrl / Cmd + クリック**は従来どおり 1 枚の切り替え。切り替えた画像が新しいアンカーになる。
- 選択中の通常クリックは従来どおり 1 枚の切り替え(アンカーも更新)。
- Shift + クリック後、アンカーは **動かさない**(続けて別の画像を Shift + クリックすると、同じアンカーからの範囲になる。ファイラーと同じ)。
- 選択がすべて解除(`clearSelection`)・一覧の再読み込み(スコープ・検索・お気に入り絞り込みの変更)でアンカーも消える。
- 範囲は、読み込み済みの一覧(`items`)の中で数える(未読み込みの続きは含めない。1000 枚の上限は §3 のまま)。
- Shift + クリック時、ブラウザの **テキスト選択が起きない**ようにする。
- 実装はフロントのみ(`gallery-store` に `anchorId` と `selectRange(id)` を追加、`gallery-grid` の onClick で Shift を判定)。IPC・DB の変更なし。

### 9.3 テスト

- Vitest: 範囲選択(アンカー → 前後どちらの方向にも)、既存の選択を保つ、アンカー無し・アンカーが一覧に無いときの 1 枚選択、Ctrl + クリックでアンカーが移る、Shift 連続クリックでアンカー固定、`clearSelection`・再読み込みでアンカーが消える。
- 09 に追加: Shift + クリックで範囲が選択され、そのまま [ダウンロード]・[削除] できる。
