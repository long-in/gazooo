# 05. UI 設計

## 1. 方針

- shadcn/ui + Tailwind CSS 4。ライト/ダーク/システム連動(`next-themes` 相当、静的エクスポート対応)。
- デスクトップアプリらしい高密度・キーボード操作重視のレイアウト。
- ウィンドウ最小サイズ 960×640。タイトルバーは OS 標準(カスタムタイトルバーは将来)。

## 2. 画面構成(ルート)

| ルート | 画面 | 概要 |
|---|---|---|
| `/` | 生成 | (v0.19: 27)メイン = 生成フォーム + 補助、右サイド = キュー、画面下 = ギャラリー帯(横スクロール) |
| `/gallery` | ギャラリー | 仮想化グリッド、検索、お気に入りフィルタ、詳細ドロワー(`?id=`) |
| ~~`/queue`~~ | ~~キュー~~ | (v0.19 で廃止。生成ページの右サイドへ移動。設計: 27) |
| `/presets` | プリセット | 一覧(名前・モデル・サイズ・プロンプト冒頭)・名前変更・削除(確認つき)・「生成画面で使う」 |
| `/models` | モデル取得 | (v0.4、設計: 12 §5。レビュー待ち)カテゴリ別のカタログ、バージョン(ベースモデル・精度)選択、ダウンロードと進捗。`?category=&base=` で絞り込み。モデルが無いときの案内から遷移する |
| `/settings` | 設定 | (v0.7: ComfyUI の起動管理セクション・起動/停止/再起動・ログ。15 §9)エンジン接続、保存先、テーマ、言語、ログフォルダを開く。(v0.17、設計: 25。レビュー待ち)エンジン / 保存先 / AI サポート / 表示の 4 タブで切り替える(`?tab=`)。[保存] はタブの外に 1 つ |

共通: 左サイドナビ(アイコン+ラベル)、右上または下部に **エンジン接続状態バッジ**(接続中 / 未接続)、実行中ジョブがある場合はミニ進捗バー。

## 3. 生成画面のワイヤーフレーム

```
┌────┬───────────────────────────────┬──────────────────────────┐
│Nav │ プロンプト [textarea]          │                          │
│    │ ネガティブ  [textarea]         │      プレビュー / 結果    │
│ 生成│───────────────────────────────│      (進捗オーバーレイ)   │
│ ギャ│ モデル [Select] 種別バッジ     │                          │
│ キュ│ サイズ [W]×[H] [比率プリセット]│                          │
│ プリ│ Steps [slider] CFG/Guidance    │  [生成] [キャンセル]      │
│ 設定│ Sampler / Scheduler            │  枚数 [1]                 │
│    │ Seed [ ] [🎲] [固定]           │                          │
│    │ ▸ 詳細(VAE/CLIP 等)          │                          │
├────┴───────────────────────────────┴──────────────────────────┤
│ 直近の生成: [thumb][thumb][thumb] …                            │
└────────────────────────────────────────────────────────────────┘
```

- v0.2 で、パラメータパネルに折りたたみ式の「顔補正」「ControlNet」セクション(各スイッチ付き)を追加する。詳細は [10-assist-features.md](10-assist-features.md) §8。
- v0.5 で、「Inpaint」セクション(スイッチ付き。参照画像・「マスクを描く」ダイアログ・強さ・マスクの拡張とぼかし・元画像への合成)を追加する。ギャラリー詳細に「Inpaint に使う」を置く。詳細は [13-inpaint-and-ai-capabilities.md](13-inpaint-and-ai-capabilities.md) §3.6。
- v0.3 で、プロンプト欄の横に「AI に相談」ボタンを置き、右側に相談パネル(回答の逐次表示・差分カードと「適用」・新しい会話・停止)を開く。設定画面に「AI サポート」(API キー・モデル・同意)を追加する。詳細は [11-ai-assistant.md](11-ai-assistant.md) §2。
- モデル種別に応じてフォームを切り替える(Flux: ネガティブ非表示、CFG→Guidance、推奨ステップ/サンプラーを初期値に)。
- 入力検証: 解像度は 64 の倍数、メモリ負荷が高い設定には警告表示。
- ショートカット: `Ctrl/Cmd + Enter` で生成、`Esc` でキャンセル、`Ctrl/Cmd + 1..5` で画面切替(v0.19 でキューを廃止したため 6 → 5)。
  - `Esc` のキャンセルは **生成画面でのみ**、ダイアログやパネルが開いていない(`role=dialog` が無い)ときに限り、実行中のジョブを取り消す(ダイアログを閉じる `Esc` と衝突しないため)。
  - ナビの各項目に `title` でショートカットを表示する(macOS は ⌘、それ以外は Ctrl)。
- プリセット: 生成フォーム上部に「プリセット」の選択(適用)と「保存」ボタンを置く。保存は名前入力のダイアログで、同名がある場合は上書きの確認を出す。適用時はシードのランダム設定などもそのまま復元する(ギャラリーの「この設定で生成」はシードを固定する点が異なる)。

## 4. ギャラリー

- `@tanstack/react-virtual` による仮想グリッド。サムネイルは遅延ロード。
- 詳細ドロワー: 原寸表示、パラメータ一覧、コピー(プロンプト/シード)、「この設定で生成」、お気に入り、エクスポート、フォルダで表示、削除(確認ダイアログ)。
- 複数選択(Shift/Ctrl クリック)でまとめて削除・お気に入り。

## 5. 状態管理

- **zustand** で以下のストアを分割:
  - `engineStore`(接続状態・モデル一覧)
  - `jobStore`(ジョブ一覧・進捗。`job://*` イベントで更新)
  - `galleryStore`(ページング・フィルタ)
  - `formStore`(生成フォームの下書き。`localStorage` でなく DB の `settings` に自動保存)
- Tauri イベントの購読は `src/lib/tauri/events.ts` に集約し、アプリルートで 1 回だけ登録する。
- サーバー状態ライブラリ(TanStack Query)は使わず、コマンド呼び出し+イベント同期のシンプルな構成とする。

## 6. 状態別 UI

| 状態 | 表示 |
|---|---|
| ComfyUI 未接続 | 生成ボタン無効化、バナー「ComfyUI に接続できません」+ [設定を開く][再接続] |
| モデル未検出 | 空状態の案内(モデル配置場所の説明) |
| GGUF ノード未導入(Flux GGUF 選択時) | 警告+導入手順リンク |
| 顔補正 / ControlNet のノード・モデル未導入、または Flux 系を選択中(v0.2) | 該当セクションのスイッチを無効化し、理由(「SD1.5 / SDXL のみ対応」「ComfyUI に ○○ が必要です」)+導入手順リンクを表示(10 §8) |
| 生成中 | 進捗バー(step/total)、プレビュー、キャンセル |
| ギャラリー空 | 空状態イラスト+「生成を始める」 |

## 6.1 エラー表示の方針

- エラーは `code` から i18n メッセージを引き、技術的な詳細(エンジンの原文)は小さく併記する。
- 実行失敗(`ENGINE_EXECUTION_FAILED`)のメッセージにメモリ不足(`out of memory` 等)が含まれる場合は、「解像度やバッチサイズを下げる」ヒントを添える。
- 生成の投入が `ENGINE_MODEL_MISSING` で失敗したときは、モデル一覧を再取得してフォームの選択を最新化する。
- 想定外の画面エラーは、アプリ全体を白画面にせず、エラー境界(再試行ボタン付き)で受ける。

## 7. i18n・アクセシビリティ

- 辞書は `src/lib/i18n/{ja,en}.ts`。キーはドット区切り(`generate.button.start`)。
- shadcn/ui(Base UI)のアクセシビリティ機能を活かし、フォーカスリング・ARIA ラベルを維持。コントラストは WCAG AA を目安。


## 追記(v0.10・承認済み): モデルの説明パネル

- 生成画面のモデル選択の候補に絵柄・重さ・NSFW のバッジを付け、選択欄の直下に「モデルの説明」パネル(用途・得意/不得意・プロンプトの書き方・必要メモリ・対応機能・[推奨設定を適用]・[AI に相談])を置く。取得ページ(`/models`)の各ファミリーにも同じ部品を使う。詳細は [18-model-profiles.md](18-model-profiles.md) §5。

## 追記(v0.11・承認済み): 画像から生成(img2img)

- 生成画面に「画像から生成(img2img)」セクション(スイッチ・元画像・強さ・構図を固定する)と [画像からアニメ調に] を置く。ギャラリー詳細にも [img2img に使う] / [画像からアニメ調に] を加える。詳細は [19-image-to-anime.md](19-image-to-anime.md) §3・§7.2。

## 追記(v0.16・レビュー待ち): 参照画像(Qwen-Image 2.1)

- 生成画面に「参照画像」セクション(スイッチ・番号つきサムネイル・プロンプトへの `<imageN>` 挿入・参照画像の大きさ(小/標準/大)・出力サイズの目安)と [指示でアニメ調に] を置く。Qwen-Image 2.1 のときだけ有効。ギャラリー詳細に [参照画像に使う] を加える。詳細は [24-qwen-reference-image.md](24-qwen-reference-image.md) §3・§6.2。

## 追記(v0.12・承認済み): 画面の整理

- 生成画面から実行状況・直近の結果を外し、右側を生成の補助(モデルの説明・参照画像・目安時間・プロンプト履歴)にする。画面共通のヘッダに実行状況を小さく表示する。キュー画面はフィルタ・検索・サムネイル・詳細・一括操作・一時停止を加える。モデル・種別の選択肢はカタログで絞り込む。詳細は [20-ui-refresh.md](20-ui-refresh.md)。

## 追記(v0.19・承認済み): 生成ページの作業台化

- 生成ページを、メイン(生成フォーム + 補助)・右サイド(キュー)・画面下全体の横スクロールのギャラリー帯の 3 領域にする。帯で画像を選んで、設定・プロンプトの読み込みや、img2img / ControlNet / Inpaint / Qwen 参照の元画像への設定ができる。`/gallery`(画像管理)は残す。`/queue` は廃止し、キューの全機能を右サイドに移す(ナビとショートカットから「キュー」を外す)。§2 の `/` の説明と §3 のワイヤーフレームは、承認後にこの構成へ置き換える。詳細は [27-generate-workbench.md](27-generate-workbench.md)。

## 追記(v0.20・承認済み): キューとギャラリーの統合

- 27 の「右サイド = キュー」をやめ、画面下部の 1 本の横スクロールの帯に統合する(左 = キューのカード、右 = 画像)。メインはフォームと補助の 2 カラム。承認後、§2 の `/` の説明を更新する。詳細は [28-unified-strip.md](28-unified-strip.md)。

## 追記(v0.21・承認済み): 見た目の刷新

- 全ページを、ダーク・高密度・パネル構成の制作アプリ風(Photoshop のようなワークスペース)にする。左をアイコンだけのツールバー、上をコンテキストバー、下をステータスバーにし、生成ページは中央にキャンバス、右にドックを置く。§1 の方針と §2 の共通部分は、承認後に更新する。詳細は [29-pro-app-look.md](29-pro-app-look.md)。

## 追記(v0.24・承認済み・実装済み): 設定の「その他」タブとデバッグログ

- 設定ページに 5 つ目のタブ「その他」(`?tab=other`)を追加し、デバッグログの ON/OFF、ログの件数・サイズ、[ログを保存…](ZIP)・[フォルダを開く]・[ログを削除…]を置く。ON の間はステータスバーに「DEBUG」を表示する。詳細は [31-debug-logging.md](31-debug-logging.md) §5。

## 追記(v0.29・承認済み・実装中): 設定の「その他」タブにバックアップ

- 「その他」タブ(31)の「デバッグ」の下に「バックアップ」セクションを置く。設定値・ギャラリー・プリセットをトグル(既定すべて ON)で選んで取得でき、復元でも区分を選べる。API キーは別チェック(既定 OFF)。操作ボタンのみで [保存] ボタンの対象外。詳細は [35-backup.md](35-backup.md) §4。
